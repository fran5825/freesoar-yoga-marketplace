# 管理員後台流程與排版順手度整理計畫（2026-09-26，票 01–10 已實作，待 Franz 看畫面）

這份記錄 2026-09-25 跟 Franz 用 grill 方式討論出的決策（Q1–Q18，全部採用建議）。目標：管理員找得到資訊、步驟少、排版跟團主／老師端一致、一眼知道下一步。

參考 `docs/organizer-usability-plan.md`、`docs/teacher-usability-plan.md`（待處理提示、列表整張可點、詳情頁下一步放最上面、共用導覽列）。票券在 `docs/superpowers/plans/admin-usability/tickets/`。

**範圍限制**：不動資料庫結構、不動狀態機、不動權限規則（管理員仍以 `User.isAdmin` 判斷，非管理員開 `/admin/*` 一律 404）；不新增批次審核、搜尋、匯出、操作紀錄；不動 V1 scope。正式環境第一位管理員怎麼建立仍未定案（`docs/engineering/first-admin-strategy.md`），不在這次範圍。

## 現況問題

- 5 個頁面頁寬有 3 種：總覽 `max-w-4xl`、列表頁 `max-w-6xl`、課程詳情 `max-w-2xl`。
- 導覽列是每頁各自貼的小字英文連結（`AdminNav`），沒有標示目前頁面，也不是共用 layout。
- 總覽只有數字卡，看不出哪一筆要處理。
- 只有課程有詳情頁；老師審核（595 行）與需求審核（378 行）把所有操作塞在列表裡。
- 沒有連結通往 `/admin/*`；`/account` 沒有管理員卡片（backlog 第 103 行）。
- 同一帳號同時是老師／團主／管理員時，各後台之間無法直接切換，要先回 `/account`。
- 標題與欄位是英文（Dashboard、Contact name…），跟團主／老師端不一致。
- 組織頁純查看，沒有審核操作。
