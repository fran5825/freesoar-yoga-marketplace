# Brand Review Checklist

Use this checklist for public-facing pages and user-facing copy.

## Must Pass

- Does this page feel like Free Soar?
- Does it express freedom, growth, wellness, and community?
- Is the tone gentle, clear, and trustworthy?
- Does it avoid aggressive sales language?
- Does it avoid looking like a generic gym/fitness platform?
- Does it preserve a high-quality modern spiritual feeling?

## Page-specific Notes

### Home

- Must communicate Free Soar as a brand-driven marketplace.
- Must show Yoga as the first strong entry point.
- Should leave room for future Wellness / Community / Academy / Retreat.

### Teacher Join

- Should make teachers feel respected, not commoditized.
- Should communicate community, quality, and growth.

### Organizer Demand

- Should feel simple and reassuring.
- Should not feel like filling bureaucratic paperwork.

### Class Enrollment

- Should be clear, safe, and low-friction.

## Low-pressure UX Review

- CTA 是否清楚但不壓迫？
- 是否避免焦慮式行銷、恐懼式 urgency、強迫稀缺感或過度轉化導向？
- 是否避免把老師低價化、商品化或競標化？
- 表單與申請流程是否降低心理負擔，而不是過早要求過多資料？
- Empty / loading / error states 是否安定、清楚、有下一步？
