# RWD / Mobile-first Checklist

Free Soar Yoga must be mobile-first because:

- Members often enroll via phone.
- Organizers may share classes via phone.
- Teachers may check demand/calendar via phone.

## Breakpoints

Review at minimum:

- 360px mobile
- 390px mobile
- 768px tablet
- 1024px laptop
- 1440px desktop

## Required Mobile-friendly Flows

- Home → create demand
- Teacher join
- Teacher profile browsing
- Demand request form
- Class detail → enrollment
- Teacher dashboard summary
- Teacher calendar read-only/usable view
- Admin core actions at least usable on tablet/desktop

## Checklist

- No horizontal scroll
- Touch targets large enough
- Forms easy to fill
- Sticky CTA where useful
- Tables/cards adapt to mobile
- Calendar has mobile-friendly list fallback
- Text readable
- Navigation accessible
