### 2. 檢查 Google Cloud Console 的「品牌」頁面

- 目的：Google 登入畫面上會顯示的應用程式名稱、logo、隱私權政策與服務條款連結，都在這裡設定。
- 做法：登入 Google Cloud Console → 找到當初申請 Google 登入金鑰的專案 → 開「品牌」（Branding）頁面 → 把現在填了什麼告訴 Claude，Claude 幫你判斷還缺什麼。
- 前置（你才能做）：登入 Google 帳號進後台。
- 相依：需要先有第 3 項（隱私權政策與服務條款頁面）和正式網域，logo 才能通過 Google 審核並顯示。

### 3. 做隱私權政策與服務條款頁面

- 前置：條款內容涉及個資，正式上線前建議請熟悉台灣個資法的專業人士看過（規劃文件 `teacher-review-standard.md` 有同樣提醒）。

## 小提醒（踩過的坑）

- **測試**：`teacher-join` 那組測試在「開發模式」（`npm run dev`）下會因為網頁還沒載入完就被點擊而失敗，用正式建置跑（`npm run test:smoke`，它會先 build）就會通過。
- **開發伺服器**：改了 `globals.css` 之後如果畫面變成沒有顏色，通常是舊的開發伺服器沒有重新編譯；停掉重開，並在瀏覽器按 Ctrl+Shift+R 強制重新整理。
