## Architecture Principle

Future growth should happen through architecture evolution, not full rewrite.

Possible additions:

| Need | Add-on |
|---|---|
| Search becomes complex | Meilisearch / Typesense / Algolia |
| Notifications increase | Queue + worker |
| Scheduling becomes complex | Scheduling service/domain module |
| App becomes necessary | API boundary + React Native / Expo |
| Enterprise billing | Organization billing module |
| Reports become heavy | Reporting service / read replica |
