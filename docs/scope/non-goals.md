# Non-goals

These items should not be built in V1 unless explicitly approved.

## Product Non-goals

- Native mobile app
- Complex AI matching
- Full marketplace payment/refund automation
- Advanced enterprise account hierarchy
- Multi-branch company administration
- Full wellness/community/academy/retreat modules
- Teacher SaaS business tools
- Complex gamification
- Advanced analytics dashboard

## Technical Non-goals

- Microservices
- Kubernetes
- Event sourcing
- Complex distributed architecture
- Full mobile app API beyond App-ready boundaries
- Advanced queue system unless notifications become heavy

## Brand Non-goals

- Pure discount platform
- Generic fitness marketplace
- Overly commercial tone
- Medical/therapeutic claims without validation
