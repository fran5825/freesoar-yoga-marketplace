# V1 Scope

## V1 Goal

Build a professional but focused Free Soar Yoga marketplace MVP that supports:

- Organizer demand requests
- Teacher onboarding and profiles
- Teacher availability
- Demand pool and teacher response
- Class session creation
- Member enrollment
- Admin management
- Email notifications
- Mobile-first user experience

## Must Have

### Public / Marketing

- Home page
- Brand introduction
- Yoga marketplace entry
- Teacher join page
- Organizer demand request entry
- FAQ / trust pages

### Teacher

- Teacher application
- Teacher profile
- Teacher dashboard
- Teacher availability calendar
- View demand pool
- Respond to demand requests
- View assigned/accepted class sessions

### Organizer

- Organizer profile
- Create demand request
- View own demand requests
- See teacher responses
- Select teacher
- Manage class/session basics

### Member

- View class session
- Enroll in class
- View enrollment status

### Admin

- Approve teachers
- Review demand requests
- Manage class sessions
- Manage enrollments
- View basic KPIs

### Notification

- Demand submitted
- Teacher response
- Class created
- Enrollment confirmed
- Basic class reminder

## Nice to Have

- Basic review system
- Basic SEO content section
- Basic dashboard analytics
- Teacher income placeholder

## Non-goals in V1

- Native mobile app
- Advanced AI recommendation
- Full payment/refund automation
- Google Calendar two-way sync
- LINE deep integration
- Advanced enterprise permissions
- Full Wellness / Academy / Retreat modules
- Complex membership subscription
- Teacher SaaS tooling
