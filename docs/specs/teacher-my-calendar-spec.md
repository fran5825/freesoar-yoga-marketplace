# 我的行事曆（第一階段：平台內月曆）：spec

建立日期：2026-10-11。來源：`/grill-with-docs`（2026-10-11，產品主人核准範圍）。相關決策：[ADR 0009](../adr/0009-teacher-google-calendar-connection.md)。名詞見 `docs/context/glossary.md` 的「行事曆」一節。

本 spec 只涵蓋 ADR 0009 的**第一階段**：平台內的月曆。不連結 Google、不顯示「Google 行程」、不改 Prisma schema。第二階段（連結 Google 日曆）另寫 spec。

## 1. 目標

老師在「我的課程」可以切換成月曆排法，一眼看到這個月哪幾天要上課、每堂幾個人報名、哪幾天有空、有哪些合作邀請在等自己。資料和清單相同，只是換一種排法（glossary：我的行事曆）。

## 2. 已決定的規則

### 2.1 入口與切換

- `/teacher/classes` 頁首下方新增「清單／月曆」切換。預設仍是清單；月曆以網址參數記住（例如 `?view=calendar&month=2026-10`），重新整理或分享網址仍停在同一個月。
- 月曆從**星期日**開始（沿用 `MultiMonthDatePicker` 的慣例），一次顯示一個月，可往前、往後切換，並有「回到本月」。
- 日期一律以台灣當地日期（Asia/Taipei）計算，避免課程跑到前一天或後一天。
- 月曆模式不套用「即將上課／草稿／過往／全部」分頁：當月所有狀態都顯示，靠樣式區分。
- 權限沿用清單：只要登入且有老師資料就能看自己的月曆；暫停中的老師也能查看（唯讀既有承諾，同清單頁 D15）。只看得到自己的資料。

### 2.2 顯示哪些東西

| 項目 | 條件 | 樣式 |
|---|---|---|
| 自己要教的課 | `teacherProfileId` 是自己；三種來源都算（團主媒合、自己開的課、團主合作開課） | 一般樣式，顯示課名＋人數（已報名／人數上限，例如 6/10） |
| 已取消的課 | 狀態 `cancelled` | 淡色＋刪除線 |
| 草稿 | 狀態 `draft` | 淡色虛線框 |
| 可授課時間 | 每週固定時段，加上例外（`blocked` 扣掉、`extra_available` 補上） | 當天格子淡色底；點進當天才列出時段 |
| 合作邀請：待確認 | 寄給自己的邀請、狀態 `pending_confirmation` | 標「待你確認」 |
| 合作邀請：已確認未開課 | 狀態 `confirmed`（尚未轉成課程） | 標「已確認，等團主開課」 |

- 合作邀請已轉成課程（`converted`）時只顯示課程本身，不重複顯示邀請；`draft`、`declined`、`withdrawn` 不顯示。範圍沿用老師總覽既有規則：團主就是自己的邀請不列。
- 系列課程在月曆上**逐場顯示**（每一天各自一格），不收合成系列卡；收合只適用清單。
- 人數算法沿用清單卡片：已報名＝該場 `confirmed` 報名數。

### 2.2.1 可授課時間怎麼算

- 顯示的是**老師自己設定的可授課時段**，不是「扣掉已排課後的空檔」：已排課或已確認的邀請不會把淡色底拿掉，課和邀請照常疊在上面顯示。當日明細的標題寫「你設定的可授課時間」，避免老師誤以為那是剩下的空檔。
- 計算沿用既有規則（schema 註解 teacher-availability D3、D4）：
  1. 先放當天星期幾的每週固定時段。
  2. 加上當天的 `extra_available` 例外。
  3. 再扣掉當天的 `blocked` 例外；**`blocked` 優先**，與 `extra_available` 重疊的部分一律算不可授課。
  4. 例外的開始、結束時間都空白代表**整天**：整天 `blocked` 表示當天完全沒有可授課時間；整天 `extra_available` 表示 00:00–23:59 可授課（仍會被 `blocked` 扣掉）。
- 扣完後還剩任一段時間，當天格子才上淡色底；明細列出剩下的時段（相鄰或重疊的時段合併成一段）。

### 2.2.2 課程放在哪一天

- 課程與邀請放在它**涵蓋的每一個台灣日期**：一般課程只有開始那一天；跨日的課（結束時間在隔天以後）從開始日到結束日每天都出現。結束時間剛好是午夜 00:00 時，不算進隔天。跨日項目的明細時間寫成「10/12 20:00–10/13 01:00」，讓老師知道會跨日。
- 月份查詢以「和該月份（台灣時間）有重疊」為準：開始時間早於月底、結束時間晚於月初。上個月開始、跨進本月的課，在本月也會出現在它涵蓋的日子。

### 2.3 版面

- **電腦版**：格子內直接列出課名＋人數；一天太多時顯示前幾筆加「還有 N 筆」，點進當天看全部。
- **手機版**：格子只放狀態色點（課程、草稿、已取消、邀請各一種顏色；可授課時間仍是淡色底）；點某一天，在月曆下方列出當日明細（含課名、時間、人數、狀態標籤、可授課時段）。預設選今天（今天不在當月時選當月第一天）。
- 375px 不得出現橫向捲動；點擊目標至少 44px。

### 2.4 點進去與返回

- 點課程 → 該堂單堂頁；點合作邀請 → 合作邀請頁。
- 從月曆點進單堂頁後，「← 回我的課程」要回到同一個月、同一天的月曆。做法：在既有 return-context 白名單加入月曆（只接受 `YYYY-MM` 月份與 `YYYY-MM-DD` 日期格式，而且日期必須在該月份內），不收任意網址。
- 單堂頁上的操作（確認或婉拒報名、開放報名、取消課程等）會把返回資訊放進表單隱藏欄位送出，操作完重新導回單堂頁。這條路徑由 server action 自己解析返回資訊，**必須一起支援月曆**；否則老師在單堂頁做完任何操作後，回去就會掉回清單。單堂頁、編輯頁與系列頁上所有會帶返回資訊的地方，都用同一套解析函式，不各自維護一份白名單。
- **編輯課程也要保留返回資訊**（清單與月曆都適用；目前清單也會在這條路徑遺失，一併修好）：單堂頁的「修改課程」連結帶上返回參數；編輯頁的「返回」連結、表單隱藏欄位，以及儲存成功後導回單堂頁的網址，都帶著同一組參數。老師從月曆進單堂頁→修改→儲存→回單堂頁→「← 回我的課程」，最後要回到同月同日。

### 2.5 讀取資料

- 月曆使用**新的、按月份、只查本人的摘要查詢**，不沿用清單的 `listOwnClassSessionsForTeacher`（它會讀出全部歷史課程與報名明細）。只讀月曆需要的欄位：課名、起訖時間、狀態、來源、人數上限、已報名人數（用計數，不讀名單）。
- 合作邀請、可授課時間、例外也只查本人、只查該月份範圍。合作邀請要帶出起訖時間；沒有日期的邀請不顯示在月曆上。
- 這些查詢放在 domain read service，頁面元件只負責排版；「每天要顯示什麼」的整理邏輯寫成純函式，方便單元測試。

## 3. 不做

- 不連結 Google、不顯示 Google 行程、不做撞期提醒（第二階段）。
- 不改 Prisma schema、不改課程或邀請的 state machine、不新增權限。
- 不在月曆上直接編輯、拖曳或建立課程；所有操作仍在單堂頁與合作邀請頁。
- 不做週檢視、日檢視。
- 團主、學員、管理員不做月曆。

## 4. 與其他工作的關係

- `teacher-series-rollup` 票 03 會把清單改成系列卡，同樣修改 `/teacher/classes` 頁面；兩邊施工時要錯開或在後做的那邊合併，避免改同一個檔案打架。月曆不受系列卡影響（逐場顯示）。

## 5. 驗收

- 單元測試：月份格子（星期日開頭、跨月補位）、台灣日期換算（UTC 跨日的邊界時間）、可授課時間（`blocked` 與 `extra_available` 重疊、整天例外、時段合併）、跨日課程每個涵蓋日都出現（含午夜結束不算隔天、上月跨入本月）、邀請篩選、每日項目排序、月曆返回參數的白名單（壞月份、日期不在月份內）。
- E2E：切換清單／月曆、切換月份、手機點日期看明細、從月曆點課再返回同月同日、**在單堂頁做完一個操作後再返回仍回到同月同日**、**從月曆進單堂頁→修改課程→儲存→返回仍回到同月同日**、375px 無橫向溢出。
- 文件：route map、glossary（如介面文字有調整）、visual acceptance checklist 同步。
