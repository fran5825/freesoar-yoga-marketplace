# Roles

## Visitor

Unauthenticated user.

Can:

- View public pages
- Browse public teachers/classes if enabled
- Submit teacher application or organizer inquiry depending on flow

## Member / Student

All authenticated users have basic Member capabilities.

Can:

- Enroll in class sessions
- View own enrollments
- Receive notifications
- Cancel enrollment if policy allows

## Organizer / Group Leader

Company club leader, welfare committee member, community leader, class leader.

Organizer capabilities are enabled by OrganizerProfile.

Can:

- Create demand requests
- View own demand requests
- View teacher responses to own requests
- Select teacher when allowed
- Manage class roster basics
- View class sessions created from own demand requests

## Teacher

Teacher capabilities are enabled by TeacherProfile.

Can:

- Create/edit profile
- Set teaching preferences
- Set availability
- View eligible demand requests
- Respond to demand requests
- View assigned/accepted class sessions
- View own calendar

## Admin

Admin is a platform management permission.

Can:

- Approve/reject teachers
- Review demand requests
- Manage organizations
- Manage class sessions
- Manage enrollments
- Add admin notes
- View basic KPIs
