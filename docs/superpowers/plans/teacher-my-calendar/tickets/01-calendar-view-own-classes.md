# 01: 清單／月曆切換，月曆顯示自己的課

來源：[spec 2.1、2.2、2.2.2、2.3、2.5](../../../../specs/teacher-my-calendar-spec.md)。

**What to build:** 老師在「我的課程」可以切換到月曆，看到一個月的課。月曆從星期日開始，可以切到上個月、下個月或回到本月，網址會記住月份。三種來源的課都顯示，格子內有人數（例如 6/10）；已取消的課用淡色加刪除線，草稿用淡色虛線框，跨日的課出現在涵蓋的每一天。電腦版的格子直接寫課名加人數，太多時顯示「還有 N 筆」；手機版的格子只放狀態色點，點某天會在月曆下方列出當日明細。點課程進單堂頁（返回月曆的部分在票 04）。

**Blocked by:** None (can start immediately)；接到頁面上的部分要等 `inline-enroll-rollup` 合併（見總覽「施工前提」）。

**Status:** done

**Workflow mode:** STANDARD

**Human Gate:** no

**Risk flags:** 新增按月、只查本人的讀取查詢（own-scoped，不放寬權限）；與 `inline-enroll-rollup` 同改清單頁，有合併衝突風險。

- [x] 「清單／月曆」切換；預設清單，月曆用網址參數記住檢視與月份，壞參數退回本月
- [x] 月份格子從星期日開始，前後月補位；「回到本月」
- [x] domain 新增按月、只查本人的課程摘要查詢（已報名人數用計數，不讀名單），以和月份重疊為條件
- [x] 「每天要顯示什麼」寫成純函式：台灣日期、跨日展開（午夜結束不算隔天）、同日排序
- [x] 狀態樣式：一般、已取消（淡色＋刪除線）、草稿（淡色虛線框）
- [x] 電腦版課名＋人數、「還有 N 筆」；手機版色點＋點日期列出明細，預設選今天或當月第一天
- [x] 暫停中的老師仍可查看；沒有老師資料時顯示空狀態
- [x] 單元測試：月份格子、台灣日期邊界、跨日展開、排序；元件或 E2E：切換、換月、手機明細、375px 無橫向溢出
