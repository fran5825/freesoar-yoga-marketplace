# 02: 可授課時間淡色底與當日時段

來源：[spec 2.2、2.2.1](../../../../specs/teacher-my-calendar-spec.md)。

**What to build:** 老師設定了可授課時間的日子，月曆格子會有淡色底；點進當天，明細會列出「你設定的可授課時間」的時段。計算方式是每週固定時段，加上加開時段，再扣掉不可授課的例外。

**Blocked by:** 01

**Status:** done

**Workflow mode:** STANDARD

**Human Gate:** no

**Risk flags:** 無（只讀本人既有資料，沿用既有 D3／D4 規則）

- [x] 按月、只查本人的每週時段與該月例外
- [x] 純函式：每週時段＋`extra_available`－`blocked`；`blocked` 優先；開始、結束都空白代表整天；相鄰或重疊時段合併
- [x] 扣完仍有時段才上淡色底；已排課不會拿掉淡色底
- [x] 明細標題「你設定的可授課時間」，列出時段
- [x] 單元測試：重疊、整天封鎖、整天加開被封鎖扣掉、合併；畫面驗淡色底與明細
