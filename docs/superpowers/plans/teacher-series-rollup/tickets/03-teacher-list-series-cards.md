# 03: 老師「我的課程」系列卡

來源：[spec 2.1](../../../../specs/teacher-series-rollup-and-action-bar-spec.md)。圖一、圖二。

**What to build:** 老師「我的課程」中屬於系列的場次收合成一張系列卡，單堂維持一場一卡。系列卡顯示標題、期班／持續開課標籤、上課時間、地點、下一堂日期、合計人數，底部顯示最急的一件待處理，點卡進系列管理頁。四個分頁依 spec 2.1 計算。

**Blocked by:** None

**Status:** 待開始 ・ **Workflow mode:** STANDARD ・ **Human Gate:** no

**Risk flags:** 分頁計數與「回到同一分頁、同一張卡」的返回位置要改成以系列為單位。

- [ ] 收合邏輯放 service layer（輸入場次清單與分頁，輸出系列卡與單堂卡混合列表），排序依分頁既有規則（以系列在該分頁內最近的場次排序）
- [ ] 人數算不重複學員（spec 2.1）：整期學員報 8 堂只算 1 位，待確認同理
- [ ] 最急待處理：待確認 > 已結束待標記完成 > 草稿待開放（沿用老師總覽排序）
- [ ] 返回位置錨點改為系列卡 id；從系列頁回來回到同一分頁
- [ ] 單元測試：混合列表、各分頁計數、最急待處理排序、整期報名跨分頁的不重複學員數
- [ ] smoke：四個分頁、系列卡進系列頁、單堂卡進單堂頁、手機 375px
