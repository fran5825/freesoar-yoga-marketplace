# 09：整期學員請假與退出整期

**What to build:** 整期學員可以只取消某一場（請假），其他場保留並釋出名額；也可以退出整期，取消之後所有未開始的場次，已上過的紀錄保留。退出後不能再報整期（推導規則 5）。

**Blocked by:** 08 學員報名整期

**Status:** draft

**Workflow mode:** HEAVY

**Human Gate:** yes

**Risk flags:** STATE_MACHINE、PERMISSION（學員 own-scoped）、NOTIFICATION

規格：[4.7](../../../../specs/teacher-class-scheduling-spec.md)（Q25）；情境 S8、S9；推導規則 5。

- [ ] 請假：取消單場報名，整期報名紀錄維持有效，名額釋出給單堂報名。
- [ ] 退出整期：確認視窗列出會取消的場次；整期報名紀錄改為已退出，底下未開始的場次取消，已開始或完成的場次不變。
- [ ] 退出後再報整期被拒，期班頁說明原因（推導規則 5，放行時確認）。
- [ ] 退出整期先鎖系列列（規格第 6 節），鎖內重新讀取場次，避免與追加補課交錯後留下有效報名。
- [ ] 只有學員本人可操作；課程開始後不能請假該場（沿用既有取消報名時間規則）。
- [ ] 通知比照現行學員取消報名：只通知學員本人，不另外通知老師（推導規則 10）；退出整期只發一則。
- [ ] Smoke 測試覆蓋請假、退出、退出後再報被拒、他人拒絕、已開始場次不受影響、退出與追加補課交錯後沒有殘留有效報名；tsc、lint、受影響 smoke 通過；RWD 檢查。
