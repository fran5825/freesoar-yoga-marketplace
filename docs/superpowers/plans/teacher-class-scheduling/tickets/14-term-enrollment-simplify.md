# 14：期班報名流程簡化

**What to build:** 學員從任何期班連結進來，在同一頁按「我要報名」就展開表單、一步報完，不必在單堂頁與期班頁之間來回。期班頁與單堂頁的課程資訊改為精簡寫法；沒填的說明卡不顯示。

**Blocked by:** 07–13

**Status:** done（2026-10-09；待產品主人看畫面）

**Workflow mode:** STANDARD（只改畫面與導向；不動 schema、權限、報名規則與鎖）

**Human Gate:** 2026-10-09 產品主人於 `/grill-with-docs` 兩輪問答確認 Q1–Q14 全部照建議，並回覆「確認，開始做」。

## 決定（Q1–Q14）

| # | 決定 |
| --- | --- |
| Q1 | 只收整期的期班：單堂連結自動轉到期班頁（例外見 Q9）。整期和單堂都收的期班保留單堂頁。 |
| Q2 | 整期和單堂都收的單堂頁：「我要報名」展開後二選一「報名整期（N 堂）」或「只報這一堂」，預設整期；不能報整期時只顯示可選的那一個。 |
| Q3 | 期班頁：「我要報名」放在課程資訊卡上，按下後在同一張卡內展開表單；報名後該區換成整期報名狀態。 |
| Q4 | 保留同意勾選；備註預設收起（「加備註」）。 |
| Q5 | 訪客按「我要報名」用 Google 登入，回來時表單已展開，由本人確認送出（不自動送出）。 |
| Q6 | 課程說明、適合對象、準備事項沒填就整張不顯示，全站課程頁一致；取代學員流程票 03 的「尚未提供」。老師端提示同步。 |
| Q7 | 單堂頁時間改為一行「日期（星期）開始–結束」；屬於期班的單堂頁另加「期間」。 |
| Q8 | 期班頁資訊卡只留期間、上課時間、地點、老師；課程風格與瑜伽類型改為標題下方標籤；報名方式寫在報名按鈕旁。 |
| Q9 | 已報名這一堂的學員不轉走，留在單堂頁（請假在這裡）。 |
| Q10 | 報名結果顯示在同一張卡內，附「查看我的報名」。 |
| Q11 | 「這一期的每一堂」預設收起，只列日期時段、自己的狀態、地點或時間不同的提示；不顯示人數。 |
| Q12 | 不能報整期時不顯示按鈕，直接在同一位置寫原因。 |
| Q13 | 期班頁手機版底部固定「我要報名」，點了回到資訊卡並展開；已報名或不能報名時不顯示。 |
| Q14 | 老師端：只收整期的期班隱藏每一堂的「複製報名連結」，只留「複製期班報名連結」。 |
