# 12：學員端期班與同系列場次呈現

**What to build:** 找課程中一個公開期班只顯示一張卡片；學員「我的課程」把整期報名合併成一張卡片，點開看每一場與請假／退出操作；單堂課程頁列出同系列其他尚未開始的場次。

**Blocked by:** 08 學員報名整期；09 請假與退出（我的課程卡片使用其操作）

**Status:** draft

**Workflow mode:** STANDARD

**Human Gate:** yes

**Risk flags:** PUBLIC_READ（只列學員本來就看得到的場次）、BRAND_RISK

規格：[4.8](../../../../specs/teacher-class-scheduling-spec.md)（Q15、Q27）；情境 S20、S21。

- [ ] 找課程：公開期班合併成一張卡片（共 N 堂、剩 M 堂、上課時間），點進期班頁；持續開課的公開場次維持逐場。
- [ ] 篩選語意依規格 4.8：任一未開始場次命中篩選就顯示；卡片堂數用整期完整數字；可報名判斷依報名方式（只收整期看能否報整期，整期和單堂都收看能否報整期或任一場有單堂空位），預設排除額滿時依此判斷。
- [ ] 「我的課程」：整期報名一張卡片，展開看每場狀態並可請假／退出（操作沿用 09）。
- [ ] 單堂課程頁：屬於系列時列出同系列其他未開始的場次，只列符合既有讀取條件的場次。
- [ ] 若本票需要放寬公開讀取條件，停止並改提 HEAVY。
- [ ] Smoke 測試覆蓋合併卡片、日期篩選只命中部分場次時卡片堂數仍為整期、只收整期且有一場滿額時不顯示為可報名、我的課程呈現、同系列場次不洩漏草稿或他人資料；tsc、lint、build、受影響 smoke 通過；375／768／1440 RWD 檢查。
