# 03：單堂詳情：資訊與報名操作順手

**What to build:** 老師進入既有單堂詳情就看得到時間、地點、狀態、人數與下一步，能開放報名、處理報名及確認取消影響。

**Blocked by:** None（可用既有課程驗收，不需等待新建表單；實作仍需本票 Human Gate）。

**Status:** draft

**Workflow mode:** STANDARD

**Human Gate:** yes

**Risk flags:** BRAND_RISK、LOW_PRESSURE_UX_RISK、SCOPE_DRIFT_RISK。

## 驗收條件

- [ ] 頂端重點摘要顯示時間、地點、狀態、已確認與待確認人數，主要操作靠近下一步；草稿先核對內容，開放後先看報名，骨架一致。
- [ ] 老師自建 draft 仍需明確開放報名；依既有資格顯示操作，不把公開可見性與開放狀態合併，不提供課程編輯或草稿學員預覽。
- [ ] 確認待審報名直接執行；婉拒先顯示學員與課程資訊及實際影響，取消單堂先顯示日期與既有報名連帶影響。
- [ ] 取消置於獨立次要區；尚未確認不呼叫 mutation。取消視窗、Escape 與返回焦點正常，pending 防止重複送出。
- [ ] 操作後留在同堂，回饋與人數更新，不因重新整理或返回重複 mutation／通知；完整列表返回上下文留 04。
- [ ] 非本人課程不能讀；團主媒合課維持既有老師操作資格，暫停者不因 UI 取得新能力。
- [ ] outcome tests 驗證 draft 開放、人數更新、直接確認、婉拒／取消前無寫入、取消視窗返回及既有狀態守門。
- [ ] 375px／768px／1440px 驗證草稿、開放、取消、長地址、空與多筆待審名單、鍵盤及 44px 操作目標。

## 實作與驗證邊界

- 可建立老師局部確認元件供本票使用，並於 05 再沿用；不修改 admin／團主的元件或新增套件。
- 既有詳情 mutations、時間限制、ownership、狀態轉換與通知保持原樣，本票只處理呈現及確認介面。
- 不包含建課、列表、系列詳情、申請或全站導覽。
- 執行 diff whitespace、TypeScript、ESLint、build、單堂詳情／own-scoped 讀取／報名確認與婉拒 smoke。
- rollback 僅回復本票呈現及測試／描述，不回復已執行的業務資料。
- 實作需本票範圍核准；如需變更權限或 state machine，停止另提 HEAVY decision plan。
