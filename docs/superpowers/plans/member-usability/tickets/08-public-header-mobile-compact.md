# 08: 公開 header 手機版精簡（票 02 未達成項目）

**What to build:** 手機（375 寬）開公開頁時，header 只佔一小條（品牌＋選單按鈕），其餘連結、登入資訊、登出、「我的專區」收進選單，課程詳情第一屏能看到標題、狀態、名額、報名鈕，並露出時間或地點。桌機版外觀不變。作法參考登入後專區導覽列（`RoleNav`）已有的手機選單，讓兩邊操作習慣一致。

**Blocked by:** None (can start immediately)

**Status:** done（2026-09-27）

**Workflow mode:** STANDARD

**Human Gate:** yes（公開 header 是首頁、關於、FAQ、老師合作、團主需求、登入頁、課程列表與詳情共用；改動會影響全站公開頁，畫面要產品主人看過）

**Risk flags:** 共用元件影響多頁；不動 Auth、schema、權限。header 內登出與「我的專區」連結行為不能變。

**Source:** `docs/member-usability-plan.md`；票 02 實作紀錄「未達成」段落
