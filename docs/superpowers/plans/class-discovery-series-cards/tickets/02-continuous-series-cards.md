# 02: 找課程列表把持續開課合併成系列卡

來源：[docs/superpowers/plans/2026-10-09-class-discovery-series-cards-plan.md](../../../2026-10-09-class-discovery-series-cards-plan.md)（D1、D2、D4–D8）。

**What to build:** 學員在 `/classes` 看到每門持續開課只有一張系列卡，內容為來源標籤、標題、老師與課程風格、一行規律（每週四 19:00）、地點、瑜伽類型、下一個有名額的場次；整張卡可點，連到票 01 的系列頁。篩選勾「包含已額滿」時改顯示最近一場並標額滿。篩選以系列為單位（任一場符合就出現一張）。頁首改「找到 N 個課程」，卡片依下一堂日期由近到遠。持續開課不顯示堂數；只剩一場仍是系列卡；期班的合併與可報名判斷維持現狀；單堂課仍一場一張。

**Blocked by:** 01

**Status:** 完成（2026-10-09，測試通過）

**Workflow mode:** STANDARD

**Human Gate:** no

**Risk flags:** 無（不改 schema、權限、state machine；沿用既有公開可見規則）。開工第一步先用本機資料庫確認截圖中「週三晨間流動瑜伽 秋季班」的 kind；若是期班卻沒被合併，另開 bug，不併入本票。

- [x] 同一持續開課 N 場只出現 1 張卡，連到票 01 的系列頁
- [x] 預設卡片的下一堂＝第一個有名額的場次；包含已額滿時＝最近一場並標額滿
- [x] 日期、時段、地點、類型篩選以系列為單位，卡片「下一堂」是符合條件的那一場
- [x] 期班行為不變（含只收整期、整期不可報時的既有結果）；單堂不受影響
- [x] 頁首「找到 N 個課程」數字等於卡片數
- [x] 規律文字與期班卡共用同一個組字函式
- [x] Vitest 涵蓋歸組、下一堂選擇、篩選、只剩一場、期班不變
