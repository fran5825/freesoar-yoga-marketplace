# 08: 總覽「待你處理」（決策 7）

**What to build:** 老師總覽最上方新增「待你處理」，依急迫度列：① 待審報名 ② 課程日期已過、尚未標記完成 ③ 草稿課程未發布。每項一行文案並連到對應頁面（詳情頁）；沒有時顯示「目前沒有待處理事項」。尚未通過審核的老師，改顯示申請狀態與下一步（沿用現有 `statusCopy`）。

**Blocked by:** 06

**Status:** done（2026-09-26）

**Workflow mode:** STANDARD

**Human Gate:** no

**Risk flags:** 只讀資料，不改狀態機；文案放 domain 層，詳情頁與總覽共用
