**What to build:** 建課預設「單堂」，「每週」「固定日期」收進「進階：重複開課」。地點、人數上限、是否需審核報名預設帶入老師最近一堂課的值。建立成功後直接進該堂課詳情頁並提示「下一步：發布開放報名」；重複開課建立後導到系列詳情。
