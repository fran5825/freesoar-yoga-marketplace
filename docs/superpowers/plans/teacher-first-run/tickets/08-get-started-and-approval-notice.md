# 08: 總覽「開始使用」與通過通知

來源：[spec](../../../../specs/teacher-first-run-spec.md)。

**What to build:** 剛通過審核的老師，總覽最上方出現「開始使用」：填收款與聯絡、開第一堂課、公開我的老師頁（可跳過），每步依現有資料自動打勾，下方有「看看團體需求」。三步完成或按「先不用」就收起來。暫停中的老師不顯示。通過通知改成同時提到開自己的課與回應團體需求，點了到老師總覽。
