# 04: 單堂報名與取消時通知老師

來源：[spec](../../../../specs/teacher-first-run-spec.md)。

**What to build:** 「報名送出即成立」的單堂課有人報名，老師收到站內通知「『課名』有新的報名」；學員自己取消單堂報名，老師也收到站內通知。單則通知點了直達該堂課的老師頁；同一系列同一天合併後，照 ADR 0008 連到老師的系列頁。學員收到的通知完全不變。

**Blocked by:** None (can start immediately)

**Status:** draft

**Workflow mode:** STANDARD

**Human Gate:** no

**Risk flags:** 通知收件人增加（不改權限、不寄 email）

- [ ] 報名即成立的單堂報名：老師收到一則站內通知、帶老師單堂 target；學員通知文案與連結不變
- [ ] 需要確認的課維持既有待確認通知，不多發
- [ ] 學員自己取消單堂報名：老師收到站內通知；老師或管理員自己婉拒或取消時不通知老師本人
- [ ] 老師不會因為自己操作收到自己的通知
- [ ] 合併後的老師通知連到老師系列頁，不是最新一堂
- [ ] 同時是老師與學員的帳號，以學員身分收到的通知目的地不變
- [ ] EMAIL_POLICY 不加老師
- [ ] smoke 測試涵蓋單則、合併、雙重身分
