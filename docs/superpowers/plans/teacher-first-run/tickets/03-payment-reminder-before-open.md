# 03: 開放報名前的收款資訊提醒

來源：[spec](../../../../specs/teacher-first-run-spec.md)。

**What to build:** 老師在任何會讓課程開始收報名的操作之前，若沒填收款帳號或收款規則，會看到對應的提醒（分開提示缺哪個），說明學員報名時拿到當下的收款資訊、之後補填不會更新給已報名的人，並附連結到「收款與聯絡」。提醒不擋操作。

**Blocked by:** 02（單堂建立時直接開放是入口之一）

**Status:** draft

**Workflow mode:** STANDARD

**Human Gate:** no

**Risk flags:** 無

- [ ] 先在程式中盤點所有老師端會把課程改成開放報名的操作，清單寫進本票進度紀錄
- [ ] 至少涵蓋：單堂課頁開放報名、單堂建立時直接開放、系列建立時全部開放、系列頁全部開放、系列單場快速開放、生成更多時直接開放、期班追加補課在全開時
- [ ] 帳號與規則分開判斷，只填規則也提醒帳號
- [ ] 提醒出現在按下之前；不填照樣可以開放
- [ ] 判斷邏輯在 domain 層共用
- [ ] smoke 測試涵蓋至少單堂與系列兩種入口
