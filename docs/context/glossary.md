# Free Soar Yoga 名詞表（Glossary）

這份文件只收錄「本專案特有」的詞，並規定介面（使用者看到的文字）要用哪個詞。程式內的 identifier 維持英文，不隨介面用詞改名。實作細節、規格與決策請看 `docs/domain/` 與 `docs/adr/`，不寫在這裡。

## 角色

**學員**：
在平台上報名並參加課程的人。介面一律稱「學員」；程式與資料模型裡的 identifier 是 `member`。
_Avoid_：會員、個人會員、Student（介面文字）

## 課程

**單堂**：
只安排一個日期的一堂課，是老師建立課程時的預設排程選項。

**每週固定**：
每週在同一個星期與時間上課的排程方式。介面入口使用「每週固定」，讓老師直接理解排程；既有「常規」指相同概念。

**指定日期**：
由老師選擇數個明確日期，使用共用時間與課程設定安排多場課的排程方式。介面入口使用「指定日期」；既有「固定期」指相同概念。是否收整期報名，看這個系列是不是期班。

**課程系列**：
共用課程設定、由每週固定或指定日期安排出的多場課。每一場仍是獨立的上課單位；學員能否一次報名多場，看這個系列是不是期班。

**期班**：
有開始也有結束、堂數在建立時就固定的課程系列，例如「3–5 月每週二晚上，共 10 堂」。學員可以報名整期，報一次就涵蓋這一期的課；老師可另外設定是否也收單堂報名。期班不能無限往後延伸，要續開就開新的一期。
_Avoid_：套裝課程、課程包（容易聯想到付費方案）、固定期（舊稱，未必收整期報名）

**整期報名**：
學員對一個期班報名一次，就報上這一期的課。與逐場報名的「單堂報名」相對。
_Avoid_：包班、套票

**單堂報名**：
學員只報名一場課。單堂課、持續開課的場次，以及有收單堂的期班場次，都用單堂報名。

**持續開課**：
每週固定、沒有預定結束的課程系列，老師可以一直往後生成新場次；學員逐場報名。與期班相對。
_Avoid_：常態班（口語可用，介面用「持續開課」）

**改課**：
老師修改已建立、尚未開始的課程內容、時間、地點、人數上限或公開設定。系列可以只改一場，或改這場和之後所有場次。
_Avoid_：編輯課程（指一般表單操作時可用，指這項功能時用「改課」）

**從這場以後全部取消**：
取消課程系列中的某一場及之後所有尚未開始的場次，之前的場次照常進行，用來中途結束一個系列。
_Avoid_：結束系列、關閉系列（系列本身沒有結束狀態）
**團主團課**：
由團主（organizer）發起需求、挑選老師後成立的課程，對應 `ClassSession.origin = organizer`。
_Avoid_：團課（太籠統，容易與「老師開課」混淆）

**老師開課**：
由老師自己建立並公開讓學員報名的課程，對應 `ClassSession.origin = teacher_initiated`。
_Avoid_：公開課、老師自開課

團主團課與老師開課在學員眼中是同一種東西：都出現在同一個課程列表，只用來源標籤區分。

**擅長類型**：
老師會教的瑜伽種類，寫在老師資料裡，可多選，可在「其他」自訂。對應 `TeacherProfile.specialties`。
_Avoid_：專長、流派（介面文字）

**瑜伽類型**：
某一堂課實際教的瑜伽種類。選項跟擅長類型是同一份清單；老師建課時必填。對應 `yogaStyles`。
_Avoid_：瑜伽風格（2026-09-26 已改名）

**課程風格**：
一堂課或一筆需求想帶給學員的感受與目的，例如放鬆紓壓、流汗活力。團主用它描述需求，老師建課時也要選。對應 `serviceTypes`。
_Avoid_：課程類型、服務類型（介面文字）

擅長類型、瑜伽類型講的是「教哪種瑜伽」；課程風格講的是「想要什麼感受」。兩者不混用。所有選項與文案一律寫「瑜伽」，不寫「瑜珈」。

## 平台與後台

**團體**：
團主所屬的單位（社團、公司、工作室等），對應 `Organization`。介面一律稱「團體」；管理員後台的頁面名稱是「團體」，不用 Organizations。
_Avoid_：組織、Organization（介面文字）

**需求**：
團主發起、等待老師回應的開課需求，對應 `DemandRequest`。介面一律稱「需求」。
_Avoid_：Demand（介面文字）

**待你處理**：
各角色總覽頁最上方的區塊，列出「現在輪到這個角色動手」的事項（管理員：待審老師申請、待審需求），每項一行、整列可點。沒有事項時顯示「目前沒有待處理事項」。

**角色切換**：
導覽列右側的「目前身分」下拉選單，列出同一帳號擁有的身分（學員、團主、老師、管理員）並可直接切換。一個帳號可同時擁有多個身分；沒有的身分不顯示。管理員身分只有管理員本人看得到。

**成為…入口**：
角色切換選單底部的「＋ 成為團主」「＋ 成為老師」，只在帳號還沒有該身分時出現，連到對應的申請頁。它取代了已移除的「我的帳戶」入口中心。

**公開 header**：
沒登入的訪客在公開頁面（首頁、課程、老師合作、發起團課、關於、FAQ、登入頁）看到的頂部導覽列。登入後不再出現，一律改用專區導覽列。
_Avoid_：首頁導覽列、網站選單

**專區導覽列**：
登入後每一頁都會出現的頂部導覽列，顯示目前所在的專區（學員專區、老師專區、團主專區、管理後台）與角色切換。
_Avoid_：後台選單、會員選單

**上次身分**：
這個帳號最後一次進入的專區所代表的身分。已登入的人打開首頁或剛登入完成時，直接從上次身分的總覽開始；這個身分已不能使用時，回到學員。記錄只存在該瀏覽器，換裝置就從學員開始。
_Avoid_：預設身分、主要身分

**建立入口放清單最底**：
老師端「＋ 建立課程」與團主端「＋ 發起新需求」不放在導覽列右上角，而是放在各自列表（我的課程、我的需求）的最底下；列表是空的時候放在空狀態卡片裡。
