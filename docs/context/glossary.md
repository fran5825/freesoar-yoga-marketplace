# Free Soar Yoga 名詞表（Glossary）

這份文件只收錄「本專案特有」的詞，並規定介面（使用者看到的文字）要用哪個詞。程式內的 identifier 維持英文，不隨介面用詞改名。實作細節、規格與決策請看 `docs/domain/` 與 `docs/adr/`，不寫在這裡。

## 角色

**學員**：
在平台上報名並參加課程的人。介面一律稱「學員」；程式與資料模型裡的 identifier 是 `member`。
_Avoid_：會員、個人會員、Student（介面文字）

## 課程

**團主團課**：
由團主（organizer）發起需求、挑選老師後成立的課程，對應 `ClassSession.origin = organizer`。
_Avoid_：團課（太籠統，容易與「老師開課」混淆）

**老師開課**：
由老師自己建立並公開讓學員報名的課程，對應 `ClassSession.origin = teacher_initiated`。
_Avoid_：公開課、老師自開課

團主團課與老師開課在學員眼中是同一種東西：都出現在同一個課程列表，只用來源標籤區分。

## 平台與後台

**團體**：
團主所屬的單位（社團、公司、工作室等），對應 `Organization`。介面一律稱「團體」；管理員後台的頁面名稱是「團體」，不用 Organizations。
_Avoid_：組織、Organization（介面文字）

**需求**：
團主發起、等待老師回應的開課需求，對應 `DemandRequest`。介面一律稱「需求」。
_Avoid_：Demand（介面文字）

**待你處理**：
各角色總覽頁最上方的區塊，列出「現在輪到這個角色動手」的事項（管理員：待審老師申請、待審需求），每項一行、整列可點。沒有事項時顯示「目前沒有待處理事項」。

**角色切換**：
導覽列右側的「目前身分」下拉選單，列出同一帳號擁有的身分（學員、團主、老師、管理員）並可直接切換。一個帳號可同時擁有多個身分；沒有的身分不顯示。管理員身分只有管理員本人看得到。

**成為…入口**：
角色切換選單底部的「＋ 成為團主」「＋ 成為老師」，只在帳號還沒有該身分時出現，連到對應的申請頁。它取代了已移除的「我的帳戶」入口中心。

**公開 header**：
沒登入的訪客在公開頁面（首頁、課程、老師合作、發起團課、關於、FAQ、登入頁）看到的頂部導覽列。登入後不再出現，一律改用專區導覽列。
_Avoid_：首頁導覽列、網站選單

**專區導覽列**：
登入後每一頁都會出現的頂部導覽列，顯示目前所在的專區（學員專區、老師專區、團主專區、管理後台）與角色切換。
_Avoid_：後台選單、會員選單

**上次身分**：
這個帳號最後一次進入的專區所代表的身分。已登入的人打開首頁或剛登入完成時，直接從上次身分的總覽開始；這個身分已不能使用時，回到學員。記錄只存在該瀏覽器，換裝置就從學員開始。
_Avoid_：預設身分、主要身分

**建立入口放清單最底**：
老師端「＋ 建立課程」與團主端「＋ 發起新需求」不放在導覽列右上角，而是放在各自列表（我的課程、我的需求）的最底下；列表是空的時候放在空狀態卡片裡。
