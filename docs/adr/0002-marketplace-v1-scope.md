# ADR 0002: Marketplace V1 Scope

## Status

Draft

## Decision

V1 will be a focused yoga group-class marketplace, not a simple content website and not the full Free Soar Life Platform.

## Included

- Teacher onboarding
- Teacher profile
- Teacher availability
- Organizer demand request
- Demand pool
- Teacher response
- Class session
- Enrollment
- Admin dashboard
- Email notification
- Brand landing pages
- RWD/mobile-first

## Excluded

- Native app
- Full payment automation
- Advanced AI matching
- Full Wellness / Academy / Retreat
- LINE deep integration
- Advanced enterprise permissions

## Rationale

This matches the Free Soar Yoga product plan while preserving focus.
