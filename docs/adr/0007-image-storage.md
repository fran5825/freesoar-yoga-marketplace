# ADR 0007: 圖片檔案存放在 Cloudflare R2，與網站主機分開

## Status

Accepted（2026-10-10，產品主人於 `/grill-with-docs` 核准「寫成 ADR」）。尚未開通帳號、尚未寫程式；實作前仍需逐票 Human Gate。上線主機另案決定，不受本 ADR 影響。

## Context

飛索要讓老師放照片（課程封面、老師頭像與個人照片），目前專案沒有任何檔案儲存，資料庫只有一個純文字的 `TeacherProfile.profilePhotoUrl`。使用者是不懂技術的瑜伽老師，要求貼網址等於沒有這個功能，所以必須支援直接上傳檔案。

上線主機還沒決定：`docs/adr/0001-tech-stack.md`（Draft）列 Vercel，產品主人也在考慮 Cloudways。Vercel 的程式執行環境沒有可長期存檔案的硬碟；Cloudways 有硬碟，但照片會跟著那台伺服器走，換主機、重建或備份出錯都會影響。

## Decision

- 照片檔案存放在 **Cloudflare R2**（物件儲存，像獨立的檔案倉庫）。網站主機與資料庫只記錄「這張照片在倉庫的哪個位置」與基本資訊，不存檔案本身。
- 圖片服務與主機解耦：不論最後選 Vercel、Cloudways 或其他主機，都不需搬照片。
- 上傳時檢查格式（JPG、PNG、WebP）與大小（單張 5 MB），並自動縮成適合網頁的尺寸；檔名使用不可猜測的隨機 key，不使用老師姓名或原始檔名。
- 帳號、金鑰（API token）與信用卡綁定由產品主人自己處理；金鑰只放在環境變數，不貼在對話、不進 Git。

## Alternatives considered

1. **Vercel Blob**：設定最少，但只適合放在 Vercel；免費方案是硬上限（超過就不能用，要等 30 天）；若最後不選 Vercel 就要搬照片。
2. **Supabase Storage**：跟主機無關，但專案目前沒有用 Supabase，會多一個帳號與服務；免費方案流量只有 5 GB，升級 Pro 每月 25 美元起。
3. **把檔案放在主機硬碟**：Vercel 不可行；Cloudways 可行但耦合主機、備份與擴充都要自己處理。
4. **只讓老師貼圖片網址**：零成本，但外部連結失效圖就消失，老師也不會操作，等於沒有功能。

## Consequences

- 多一個外部服務與一份帳單：免費額度為每月 10 GB 儲存、流量不收費；照片縮成約 300 KB 後約 3 萬張才用完，試用期預期費用為 0。超過後每 GB 每月 0.015 美元。據我們了解開通時需綁信用卡，以實際畫面為準。價格以 [Cloudflare R2 官方頁面](https://developers.cloudflare.com/r2/pricing) 為準，上線前需再確認。
- 之後若要換儲存服務，需搬移所有照片並更新資料庫裡的位置；不難，但繁瑣，這是寫成 ADR 的原因。
- 資料庫要新增照片資料表，以及課程、課程系列、老師頁引用照片的欄位（見 `docs/specs/teacher-showcase-photos-spec.md`）；`docs/domain/data-model.md` 需在對應票同步更新。
- 隱私：沒公開的照片不能出現在任何公開頁面，也不能被列出；檔案網址使用不可猜測的 key。老師刪除或管理員下架的照片，要立即從所有頁面隱藏，倉庫裡的實際檔案另行清除。
- 第三方服務出狀況時，照片會暫時顯示不出來，但報名、付款狀態等核心流程不受影響（頁面要能在沒有照片時正常顯示，見「有填才顯示」）。
