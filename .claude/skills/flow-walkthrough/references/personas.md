# 固定 persona

每個角色 3 位，刻意選「卡點不同」的人：一位熟悉舊方法、怕麻煩；一位目標明確、只想快點拿到結果；一位挑剔、要被說服。每次走查都用同一組人，不同次的報告才比較得起來。

產品主人如果認識真實的老師或學員、覺得某位 persona 不像，直接改這份檔案。
